ICE

ICE contains links to small projects that helped me practice using HTML and CSS in various ways. Each project showcases different techniques and concepts I have learned while working with HTML and CSS. The top paragraph provides a desription of the project, while the bottom one provides a summary of what I learned. To the right is a pink button that opens up to the completed project.

Project One:
Prophet Card

This project demonstrates the creation of a Prophet Card featuring President Oaks from the Church of Jesus Christ of Latter-day Saints. This card includes a photo of President Oaks, his name, brief details about him, and a quote from one of his talks.

For this project, I learned a little more about using grid in CSS and utilizing some interactive features, such as hover effects.

Project Two:
Apostle Spotlight

This project displays the Quorum of the Twelve Apostles from the Church of Jesus Christ of Latter-day Saints, along with the Presidency. Each figure is represented with a round portrait photo.

For this project, I learned how to create a responsive layout using CSS grid and how to style images to maintain a consistent appearance. I also learned through a reel YouTube video on how to implement a colorful gradient effect between two colors when you hover, which introduced me to the usage of gradient to create a colorful spectrum effect.

>>>

Project Three:
Favorite Devotional Table

This project creates a table displaying my favorite devotional talks from the Church of Jesus Christ of Latter-day Saints. Each row includes the title of the talk, the speaker, and a brief summary. At the bottom features a button to click on to open up to a form to potentially submit more devotional talks.

For this project, I learned how to structure and style tables in HTML and CSS, ensuring readability and a clean layout. I also learned how to create a form, and that in order to create a pop-up form, you need to use Javascript. I ended up choosing to not dive into implementing the pop-up form using Javascript just yet and decided to create a button to open up in a new page for the form for a cleaner layout.

>>>

Project Four:
Holiday Page

This project creates fun page dedicated to Halloween. The HTML was already prestructured and not to be tampered with, so my main focus went into creating a unique and engaging design for the page. I think I had the most fun with this page, though I also ran into a CSS challenge that took me the longest to figure out.

This project taught me how to work within the constraints of prestructured HTML while still creating a visually appealing and engaging page. For the colorful moving gradient behind the Halloween picutre, I followed a YouTuber's video to create the design. However, that design only gave me an example where I felt like I needed to make changes to the HTML to be successful, which while I was able to figure out that design, it wasn't right for the requirments of the project. So, it lead me to disovering a way through just CSS to still accomplish the desired effect through the usage of anchor in CSS, which I found very useful.

Project Five:
Country Flags with a Grid

This project uitilizes the usage of grid to create various country flags.

This project taught me how to effectively use CSS Grid to create simple layouts, and that with grid, items will fall into place naturally on the grid in the order they appear in the HTML. I decided to implement a hover effect from a website with unique CSS hover animations that would work with with the flags, and surprisingly, it was fairly easy to implement without much extra help.

This project focused on understanding and applying CSS positioning techniques. There were already prestructured HTML elements, and my task was to imitate image examples to create the desired effect through CSS positioning techniques.

This project taught me the importance of understanding CSS positioning, though it still is a little confusing for me to fully grasp. I think I need more practice with it to fully memorize what each positioning does to affect items and their position.

Project Seven:
Image Gallery Issues

This project required me to change the image sizing for each photo used to create a better loading rate and simplify space usage.

Through the usage of Photopea, I downsized the images and was able to learn png can hold more file weight than jpeg files. It makes sense that the upload speed for pages would be slower with larger images. To add some special hover effectst that seemed fitting for this page, I tried to implement a unique hover effect from the same website I've been utilizing for the pase few projects, as well as learned that in order to create certein curso effects, Javascript would be needed.

Project Eight:
Signup Form Design

This project involved designing a signup form with a close button, including some Javascript prewritten to accomplish that effect.

This project taught me a little more about the importance of creating responsive web pages and making sure to implement good structured CSS to enable all sorts of screen sizes. I also decided to add a form button that appears once you close the form so that the user can reopen the form after closing. It gave me a better look at Javascript, though there's still much more to learn.
